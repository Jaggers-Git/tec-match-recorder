Setup checklist

Nothing here is required. Green is ready, yellow needs a look, grey is an optional extra.

    Enter the PIN

    This dashboard is being opened from another device. Type the PIN shown under Settings, Network access, on the recording PC.

    How to

    1. Pick the setTap it in the bracket list on the left (in pools, tap the pool first: the same letter repeats in every pool), or type both player names on the right. Players on the wrong sides? Tap ⇄ swap. Recording Street Fighter or Tekken by hand? Set the game in the dropdown above the names (sets picked from start.gg set it for you).
    2. Start recordingPress START RECORDING when the players sit down. Characters fill in by themselves once the game starts (chips marked auto); fix them with Characters… if needed. Names can be edited any time before saving.
    3. End & saveWhen the set is over, press END & SAVE, then press it again to confirm. The file is named and saved, and the form clears for the next set.

    Setting up the station, or something looks wrong? Open the .

    Before the first set

    1. Start OBS. Check the capture card picture and game audio in the preview.
    2. Run Start Recorder.bat and leave its black window open.
    3. The header should show OBS connected and start.gg LIVE in green, or "manual mode" if there is no bracket loaded.

    Rules of thumb

    • One recording per set (the whole Bo3/Bo5), not per game.
    • The file is named from whatever is in the form when you press End & Save.
    • Don't press Stop inside OBS. If someone does, the app still labels the file.
    • Players play off the passthrough monitor, never the OBS preview.

    Every set

    1. Pick the set in the bracket list (same letters as the bracket), or type both names. Recent names auto-suggest.
    2. Players on the wrong sides? Tap ⇄ swap. Nobody has to move.
    3. Characters fill in by themselves once the game starts (chips marked auto). Fix or add with Characters….
    4. START RECORDING as soon as the players sit down. Names can still be fixed while recording.
    5. Set over: END & SAVE, then tap it again to confirm. The file is named and logged; the form clears.
    6. Filling the stream worksheet? Copy row on the log line and paste it in.

    If something looks wrong

    OBS not connectedIs OBS open? In OBS: Tools, WebSocket Server Settings, Enable must be ticked. It reconnects on its own.
    OBS: wrong passwordSettings, OBS, paste the password from OBS's Show Connect Info.
    vMix not connectedIs vMix open? In vMix: Settings, Web Controller, Enable must be ticked (port 8088). It reconnects on its own.
    vMix: wrong passwordSettings, vMix: the user name and password from vMix's Web Controller settings.
    vMix did not start recordingIn vMix: Settings, Recording. Check the folder exists and the format is set.
    start.gg OFFLINEWi-Fi dropped. Keep going with the bracket you see; tap Sync now when it's back.
    start.gg errorToken or URL problem. Recording still works; enter names by hand and tell the TO.
    Detect: off or untrainedCharacters won't fill in by themselves. Tap them in with Characters….
    Disk chip redUnder 25 GB left. Tell the TO before the next set.
    Log row says errorTap Retry. The video is safe in the OBS folder either way.
    Black window closedRun Start Recorder.bat again. A recording in progress keeps going in OBS.
