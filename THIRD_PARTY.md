# Third-party material

- **Urban Constructed font** (`public/fonts/UrbanConstructed-Regular.ttf`, display font for the dashboard and stream overlay in both themes): by Nils von Blanc (www.nils-von-blanc.de), inspired by Jakob Fischer / PizzaDude's "Nonstop". Licensed under Creative Commons Attribution-Noncommercial 3.0 Unported (http://creativecommons.org/licenses/by-nc/3.0/), not under this project's MIT license. Free for noncommercial use; commercial use needs the author's permission (vonblanc@gmx.de). If your streams are commercial, get that permission or swap the font: remove `'Urban Constructed'` from `--display` in `public/style.css` and from `public/overlay.html`, and the bundled OFL fonts below take over. License text: `public/fonts/LICENSE-UrbanConstructed.txt`.
- **Tomorrow font** (`public/fonts/`, fallback display font): by Tony de Marco and Monica Rizzolli, SIL Open Font License 1.1. The license text is in `public/fonts/OFL.txt`.
- **Silkscreen font** (`public/fonts/Silkscreen-Bold.ttf`, Tuesday Takedown overlay fallback): Copyright 2001 The Silkscreen Project Authors, SIL Open Font License 1.1. License text: `public/fonts/OFL-Silkscreen.txt`.
- **Oswald font** (`public/fonts/Oswald-Variable.ttf`, Tuesday Takedown dashboard fallback): Copyright 2016 The Oswald Project Authors, SIL Open Font License 1.1. License text: `public/fonts/OFL-Oswald.txt`.
- **Event logos** (themes such as Tuesday Takedown): the series' own artwork, saved from start.gg or picked by the operator into `data/branding/` on the station PC. Not part of this repository or its releases.
- **Character artwork**: Super Smash Bros. Ultimate character portraits and stock icons are Nintendo's property. They are not part of this repository or its releases. Settings offers to download the community pack from the TournamentStreamHelper assets repository (https://github.com/joaorb64/StreamHelperAssets) onto your own PC. Use it within Nintendo's community tournament guidelines.
- **OBS Studio** and **obs-websocket**: the recorder talks to OBS over the obs-websocket 5 protocol using Node's built-in WebSocket client. No OBS code is included.
- **start.gg**: bracket data comes from the start.gg GraphQL API under your own API token and start.gg's terms.
- **Node.js runtime** (`node.exe` in the portable zip only): copied unmodified from the official Node.js distribution, under the Node.js license (https://github.com/nodejs/node/blob/main/LICENSE). Not part of the source repository.
